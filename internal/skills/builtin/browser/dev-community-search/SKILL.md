# DEV Community search

Use this skill for practitioner tutorials and experience reports. DEV articles show working setups and gotchas in plain language — verify before trusting.

## When to use

- Learning a practical setup step by step.
- Comparing how practitioners solved one problem.
- Finding beginner-friendly explanations.

## Procedure

1. Search DEV for the specific stack and version.
2. Prefer recent articles matching the pinned versions in use.
3. Test the key steps instead of trusting them; report what failed.
4. Cross-check critical claims against official docs.
5. Cite the article with its date.

## Output

Practitioner guidance with verified steps and dates.

## Pitfalls

- Tutorial versions rot fast; match versions exactly.
- Test, don't trust, tutorial commands.
