# Hacker News search

Use this skill for practitioner signal: launch threads, war stories, and critical comments that surface what documentation never mentions.

## When to use

- Gauging real-world experience with a tool or approach.
- Finding launch context and alternatives.
- Reading critical takes before adopting.

## Procedure

1. Search stories for the topic and rank by substantive discussion, not points alone.
2. Read the top critical comments first; they hold the failure modes.
3. Separate practitioner reports from speculation and marketing.
4. Follow through to primary sources linked in threads.
5. Attribute opinions as opinions with links.

## Output

Practitioner-weighted findings with linked threads.

## Pitfalls

- Votes measure popularity, not correctness.
- Threads age; check dates before trusting.
