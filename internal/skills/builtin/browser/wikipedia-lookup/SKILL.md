# Wikipedia lookup

Use this skill for orientation on unfamiliar topics. Wikipedia maps the territory and points at primary sources — it starts research, never ends it.

## When to use

- Orienting on an unfamiliar topic or term.
- Finding the vocabulary and primary references.
- Settling a background fact quickly.

## Procedure

1. Read the article for structure, terms, and the reference list.
2. Follow the cited primary sources for anything that matters.
3. Check the article's date, talk page, and dispute flags on contested topics.
4. Never cite Wikipedia for load-bearing claims; cite what it cites.
5. Record the primary sources actually used.

## Output

Orientation notes with primary sources followed.

## Pitfalls

- Wikipedia is a map, not a source; cite upstream.
- Contested topics need the talk page, not just the article.
