# Hypothesis testing

Use this skill to test claims properly. Pre-registered hypotheses, adequate power, and the right test separate discoveries from noise.

## When to use

- A claim needs empirical support.
- Designing an experiment or A/B test.
- Interpreting p-values or intervals.

## Procedure

1. State the hypothesis and its falsification criterion before collecting data.
2. Design for power: sample size, controls, and randomization up front.
3. Pre-register the analysis plan to block HARKing.
4. Run the right test for the data; report effect sizes with intervals, not just p-values.
5. Publish negatives; they are results too.

## Output

Tested hypotheses with design, statistics, and honest reporting.

## Pitfalls

- HARKing invents discoveries; pre-register the plan.
- Underpowered tests waste data; size them first.
