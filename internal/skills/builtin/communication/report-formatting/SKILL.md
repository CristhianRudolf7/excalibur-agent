# Report formatting

Use this skill for anything the user will keep, forward, or publish. A good report mirrors the user's own templates and puts the conclusion first, evidence after.

## When to use

- Delivering results, investigations, or comparisons.
- The user or project has templates for reports or handoffs.
- A chat summary must become a durable document.

## Procedure

1. Pick the user's template when one exists; otherwise use conclusion, findings, evidence, next steps.
2. Put numbers and verdicts up front; relegate method and raw data to later sections.
3. Match the formats the user already uses: units, date style, file format.
4. Cite sources or evidence IDs for every non-trivial claim.

## Output

A report in the user's format and template, conclusion-first with cited evidence.

## Pitfalls

- Never bury the conclusion at the end.
- No uncited claims in a deliverable.
