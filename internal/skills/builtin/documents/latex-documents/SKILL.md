# LaTeX documents

Use this skill for papers, reports and slides in LaTeX. Compile often, read the log's first error, and keep figures and bibliography reproducible.

## When to use

- Writing or fixing `.tex` documents, beamer slides or TikZ figures.
- Undefined references, missing citations or overfull boxes.
- Setting up a compilable LaTeX environment.

## Procedure

1. Ensure the toolchain: `pdflatex --version` or `xelatex`/`lualatex` for Unicode fonts; install `texlive-latex-base` plus extras as needed (see `apt-offline-installs`).
2. Compile the full cycle: `pdflatex doc && bibtex doc && pdflatex doc && pdflatex doc`; use `latexmk -pdf doc` to automate reruns.
3. Read errors top-down: the FIRST `!` line is the cause, later ones are fallout; fix it, recompile, repeat. `?` prompts mean batch mode is off — prefer `-interaction=nonstopmode`.
4. Fix references by compiling twice; fix citations by running bibtex between runs; track overfull `\hbox` warnings and reword or resize the offender.
5. Keep figures as vector PDF (matplotlib `savefig(...pdf)`, TikZ) and data-driven tables generated by scripts, never hand-copied numbers.

## Pitfalls

- Deleting `.aux`/`.bbl` mid-debugging hides reference errors temporarily; clean fully (`latexmk -C`) for the final verification build.
- Fragile commands in moving arguments (captions, section titles) need `\protect`.
- Committing only the PDF without sources makes the document unfixable; sources are the artifact.

## Verification

- `latexmk -pdf` exits 0 with no `!` errors, no undefined references/citations, and the PDF opens with all figures and bibliography entries present.
