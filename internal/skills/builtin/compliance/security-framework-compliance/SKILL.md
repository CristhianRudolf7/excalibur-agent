# Security framework compliance

Use this skill to turn daily work into audit evidence. Controls mapped to artifacts, collected continuously, make certification a review instead of a scramble.

## When to use

- Preparing for ISO 27001, SOC 2, or similar.
- Customers ask for security evidence.
- Controls exist but evidence scatters.

## Procedure

1. Map the framework's controls to the organization's actual practices.
2. Collect evidence per control from systems and records, dated and sourced.
3. Close gaps with assigned owners before the audit window.
4. Package evidence per control for the auditor's walkthrough.
5. Keep collection continuous; point-in-time scrambles fail.

## Output

Per-control evidence packages ready for audit.

## Pitfalls

- Practices without evidence fail audits; collect continuously.
- Scrambles before audits signal missing process; fix the process.
