# Course creation

Use this skill to build a course for one learner. Syllabus, lessons in the format that fits the topic, and quizzes that actually test understanding — paced to the learner's level.

## When to use

- The user wants to learn a topic deeply.
- Training material is needed for someone else.
- Structuring scattered knowledge into a curriculum.

## Procedure

1. Fix the learner's level, goal, and available time before writing anything.
2. Draft the syllabus: modules, lessons, prerequisites, and outcomes per module.
3. Write lessons in the format each topic needs: explanation, example, exercise.
4. Add quizzes with answer keys: choice and matching questions tied to outcomes.
5. Publish through the classroom app and track progress and results.

## Output

A complete course: syllabus, lessons, quizzes with keys, published and tracked.

## Pitfalls

- Teach to the learner's level, not to the topic's prestige.
- Every module needs an outcome and a way to test it.
