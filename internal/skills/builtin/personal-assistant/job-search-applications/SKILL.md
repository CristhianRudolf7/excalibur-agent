# Job search applications

Use this skill for job hunting support. Real experience matched honestly, tailored materials that never invent, and every application tracked — with confirmation before anything goes out.

## When to use

- Searching offers or evaluating fit.
- Tailoring a CV or cover letter to a posting.
- Tracking applications and follow-ups.

## Procedure

1. Search offers against the user's stated criteria; record source and date per lead.
2. Score fit from documented experience only; flag gaps explicitly.
3. Adapt CV and letter per posting without adding a single invented fact.
4. Confirm with the user before submitting anything, anywhere.
5. Track every application: where, when, what version, next action.

## Output

Leads, honest fit scores, tailored materials, and tracked applications.

## Pitfalls

- Invented experience is fraud; verify every claim against the record.
- Nothing submits without the user's explicit yes.
