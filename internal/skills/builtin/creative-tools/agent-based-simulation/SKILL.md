# Agent-based simulation

Use this skill to explore dynamics, not to predict people. Agent rules produce patterns worth discussing — with the realism disclaimer attached, always.

## When to use

- Exploring social or market dynamics qualitatively.
- Testing mechanism designs against strategic behavior.
- Teaching emergence and feedback effects.

## Procedure

1. Define agents, rules, and environment with explicit simplifications.
2. Declare up front that behavioral realism is not validated.
3. Run scenarios varying the key parameters, with seeds recorded.
4. Interpret patterns and sensitivities, never point predictions.
5. Report assumptions alongside every conclusion.

## Output

Scenario explorations with declared limits, never predictions.

## Pitfalls

- Unvalidated agents do not predict humans; say so every time.
- Point predictions from toy rules mislead; report patterns.
