# 3D modeling

Use this skill for 3D geometry work. Units and precision set first, operations verified in views, dimensions recorded — models that manufacture or render correctly.

## When to use

- Creating or editing 3D models.
- Preparing geometry for render or print.
- Fixing dimensions or transforms.

## Procedure

1. Set units, grid, and precision before creating anything.
2. Build with solids and modifiers; name parts for later selection.
3. Verify transforms in multiple views with exact dimensions.
4. Check manifoldness and scale for the target use (print, render, export).
5. Save versions with notes; export in the required format.

## Output

Verified 3D geometry with correct units and dimensions.

## Pitfalls

- Wrong units ruin prints; set them first.
- Unverified exports fail downstream; check in the target tool.
