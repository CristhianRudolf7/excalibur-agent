# Floor plan design

Use this skill for plans and interiors. Real dimensions, circulation, and code constraints shape layouts that can actually be built and lived in.

## When to use

- Drawing floor plans or room layouts.
- Placing furniture in a model.
- Checking fit, flow, or code compliance.

## Procedure

1. Capture real dimensions and openings before drawing walls.
2. Lay out circulation first: doors, paths, and clearances.
3. Place furniture to scale with use clearances, not just fit.
4. Check constraints: structure, services, light, and applicable codes.
5. Deliver dimensioned plans plus views for review.

## Output

Dimensioned plans with circulation and constraints checked.

## Pitfalls

- Unmeasured plans fiction; measure first.
- Circulation drawn last never fits; draw it first.
