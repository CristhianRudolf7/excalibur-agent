# Whiteboard explanations

Use this skill when the user needs to see thinking happen. Live schemes, steps, and annotations on the whiteboard teach faster than paragraphs.

## When to use

- Explaining a concept, plan, or result visually.
- Walking through steps the user must follow.
- A static document is not landing.

## Procedure

1. Open the board and frame the question in one line.
2. Draw the scheme progressively, narrating each addition.
3. Annotate the decision points and the chosen paths.
4. Leave a clean final board: summary plus the key diagram.
5. Save or export the board for later reference.

## Output

A live explanation with a saved final board.

## Pitfalls

- Finished diagrams presented at once teach less; build them live.
- Unsaved boards evaporate; export the final state.
