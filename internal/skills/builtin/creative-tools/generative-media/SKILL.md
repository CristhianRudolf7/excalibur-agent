# Generative media

Use this skill for AI-generated media that serves the piece. Costed, licensed, and reviewed generations fill gaps stock cannot — within the authorized budget.

## When to use

- A shot, voice, or asset cannot be captured or licensed.
- Extending or cleaning existing footage.
- Prototyping visuals fast.

## Procedure

1. Define the exact gap the generation fills and its acceptance bar.
2. Generate within the authorized budget; report cost per asset.
3. Review every output at delivery size for artifacts, hands, and text.
4. Check license and likeness constraints before using anything.
5. Keep prompts and seeds with the project files.

## Output

Reviewed generated media with cost, license, and reproduction data.

## Pitfalls

- Budgets bind; track spend per asset.
- Artifacts ship when nobody looks closely; look closely.
