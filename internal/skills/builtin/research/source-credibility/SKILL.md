# Source credibility

Use this skill before trusting a source. Reliability, recency, and incentives decide weight — and primary evidence outranks retellings every time.

## When to use

- A claim rests on one or two sources.
- Sources conflict with each other.
- High-stakes content cites fuzzy origins.

## Procedure

1. Identify the source type: primary data, expert analysis, or retelling.
2. Check date and context: does it describe the present claim or an older one.
3. Look for conflicts of interest: who benefits if this is believed.
4. Prefer primary evidence; mark secondary claims as such.
5. Carry the credibility note with every citation downstream.

## Output

Per-source credibility notes with type, date, incentives, and weight.

## Pitfalls

- Recency is not reliability; check both.
- Undisclosed incentives discount the claim.
