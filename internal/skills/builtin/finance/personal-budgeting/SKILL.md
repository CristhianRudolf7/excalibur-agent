# Personal budgeting

Use this skill to give money a plan. Categorized spending against explicit budgets, reviewed monthly, turns vague anxiety into concrete trade-offs.

## When to use

- Building or reviewing a personal budget.
- Spending drifts without explanation.
- Planning for a goal or a tight period.

## Procedure

1. Categorize recent spending from real records, not memory.
2. Set budgets per category with the user's priorities, not ideals.
3. Track against budget monthly; explain variances concretely.
4. Adjust budgets or habits explicitly; silent drift voids the plan.
5. Keep an emergency buffer outside the spending plan.

## Output

A working budget with categorized tracking and variance notes.

## Pitfalls

- Memory lies about spending; use records.
- Guidance, not financial advice; say so when it matters.
