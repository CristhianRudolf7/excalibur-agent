# Motion design

Use this skill when motion earns its place: guiding attention, showing causality, softening transitions. Every animation respects reduced-motion settings and finishes fast.

## When to use

- Adding transitions or animated feedback.
- Motion could explain a state change.
- Reviewing animation for comfort and performance.

## Procedure

1. Give each animation a job: orient, confirm, or delight — in that priority order.
2. Keep durations short and easing natural; motion never blocks input.
3. Honor reduced-motion preferences with instant, complete state changes.
4. Test on a constrained device; jank disqualifies the effect.
5. Remove any animation that survives only because it looks clever.

## Output

Purposeful, fast, reduced-motion-safe animations.

## Pitfalls

- Motion that blocks or delays input is a bug.
- No animation without a reduced-motion path.
