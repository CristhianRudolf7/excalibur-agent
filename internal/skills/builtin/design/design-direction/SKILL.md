# Design direction

Use this skill before any visual work. A defined direction — audience, tone, references, constraints — keeps every later choice consistent instead of drifting per screen.

## When to use

- Starting a design task without a defined style.
- The product's identity must guide new work.
- Stakeholders disagree about 'the look'.

## Procedure

1. Read the commission: audience, goal, constraints, and existing identity.
2. Collect 3-5 reference directions with what each borrows and what it rejects.
3. Define the direction: tone words, visual anchors, and non-goals.
4. Get explicit agreement on the direction before producing screens.
5. Keep the direction note linked to all derived artifacts.

## Output

An agreed design direction with references, anchors, and non-goals.

## Pitfalls

- No screens before an agreed direction.
- References are anchors, not templates to copy.
