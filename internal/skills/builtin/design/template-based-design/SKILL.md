# Template-based design

Use this skill for presentations and posters under time pressure. A gallery template gives structure; adaptation to content, size, and identity makes it yours.

## When to use

- A presentation or poster is due quickly.
- Layout from scratch would waste the budget.
- Brand consistency across decks matters.

## Procedure

1. Pick a template whose structure matches the content, not just its looks.
2. Set size and orientation first: horizontal deck versus vertical poster changes everything.
3. Replace every placeholder with real content; adjust hierarchy to the message.
4. Apply the product identity: colors, type, logo placement per the system.
5. Check readability at the actual viewing distance or screen size.

## Output

An adapted template deck or poster with real content and identity applied.

## Pitfalls

- Leftover placeholder text ships embarrassment; hunt it all.
- Orientation is structural; decide before designing.
