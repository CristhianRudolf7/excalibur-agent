# Style catalog

Use this skill to ground style proposals in real examples. Options shown side by side with their trade-offs let the user choose taste quickly instead of describing it.

## When to use

- The user wants 'something modern' without specifics.
- Proposing alternative looks for one product.
- Moodboards or style tiles are due.

## Procedure

1. Gather the product constraints: brand, audience, platform, accessibility floor.
2. Collect style examples covering distinct directions, each with a source.
3. Present options side by side with one-line trade-offs each.
4. Record the chosen style and its rejected siblings with reasons.
5. Carry the choice into the design system documentation.

## Output

Style options with sources and trade-offs, and a recorded choice.

## Pitfalls

- Options without trade-offs force choice by gut alone.
- Respect example licenses; note sources.
