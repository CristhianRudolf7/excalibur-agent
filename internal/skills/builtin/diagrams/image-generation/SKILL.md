# Image generation

Use this skill when an original image is needed. Prompt craft plus cost and license reporting keeps generated imagery deliberate and above board.

## When to use

- Illustrations, covers, or placeholders are needed.
- Stock cannot express the concept.
- Mockups need visual material fast.

## Procedure

1. Define the need: subject, style, size, and where it ships.
2. Write a concrete prompt: composition, palette, mood, and explicit exclusions.
3. Generate and review at delivery size; iterate on what fails.
4. Report cost and the model's license terms for the use.
5. Record the prompt and seed with the asset for reproducibility.

## Output

Reviewed generated images with cost, license, and reproduction data.

## Pitfalls

- Generated images carry license terms; report them.
- Text in generated images usually fails; verify letter by letter.
