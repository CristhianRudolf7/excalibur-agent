# Presentations

Use this skill for decks that persuade. Structure, speaker notes, and honest charts carry the message; decoration never substitutes for a clear storyline.

## When to use

- Building or editing PPTX or Slides decks.
- Adapting a deck to a new audience or time slot.
- Charts and notes must survive editing.

## Procedure

1. Fix the storyline first: one message per slide, ordered for the audience.
2. Build with masters and layouts; no manual text boxes mimicking structure.
3. Write speaker notes carrying what slides imply but do not say.
4. Rebuild charts from data after edits; check every number.
5. Rehearse the flow at the real aspect ratio and font sizes.

## Output

A coherent deck with notes, verified charts, and clean masters.

## Pitfalls

- Manual boxes instead of layouts break every later edit.
- Unverified chart numbers embarrass publicly; check each.
