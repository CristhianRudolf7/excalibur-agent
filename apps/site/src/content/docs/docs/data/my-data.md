title: 'My data'
description: 'Create a collection for information you want to track and update.'
---

Use My data to organize information as collections of records. A collection defines the fields; each record holds one item's values. You can browse and edit these records in the application or ask your agent to work with them in conversation.

## Create your first collection

Ask for the information you want to track. For example:

> Create a collection for books I want to read, with title, author, and reading status. Show me the fields before creating it.

Excalibur's collection tool proposes a schema before creation. Review the field names, types, required values, and any constraints. Confirm the proposal when it matches your needs. Example rows in a proposal are fictional sample data and should not be treated as records you supplied.

After creation, open My data and select the collection. The overview shows its description, record count, and update date. Inside a collection you can search records, filter by fields, sort, and open a record's details.

## Keep records useful

Add or edit records through the collection's forms. Fields can hold typed values such as numbers, dates, choices, and relations to another collection. Required fields and configured constraints are checked when values are saved. Relations can link to a related record rather than repeating the same text everywhere.

Creating a collection and changing its structure are different from editing a record. The assistant requires confirmation for collection creation, deleting a whole collection or field, and potentially lossy type changes. Individual record insertions, updates, and deletions do not have that same tool confirmation gate.

Start with a small schema and inspect the saved collection before adding more information. If your data already lives in a file, follow [Import a spreadsheet](/docs/data/import-spreadsheet/). See [Collection views and forms](/docs/data/interfaces/) for everyday browsing and export controls.
