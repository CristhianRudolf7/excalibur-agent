Adjunta un documento a una conversación o agrégalo a la biblioteca cuando quieras que Excalibur trabaje con su contenido. Necesitas la aplicación conectada y un proveedor de modelos configurado para recibir respuestas. El procesamiento debe terminar antes de que esté disponible todo el texto extraído.

## Consulta un archivo

1. Adjunta el documento y espera a que avance su carga y procesamiento.
2. Haz una pregunta concreta, por ejemplo: “¿Qué condiciones de cancelación establece este documento? Cita los pasajes relevantes”.
3. Abre las citas numeradas o el control de fuentes de la respuesta.
4. Compara el pasaje con el visor o con el archivo original.

El cargador web admite documentos de hasta 64 MiB. La carga y el procesamiento son pasos distintos. Que la carga termine no significa que la extracción esté completa. La biblioteca puede mostrar documentos pendientes, en procesamiento, listos, parciales o con errores.

## Lee las citas en contexto

Las fuentes documentales pueden señalar una página, un párrafo y un fragmento. Al seleccionar una cita de documento, se abre su fuente en el visor. Una fuente web puede abrir la página original. Un número sin una fuente asociada no sirve como enlace para comprobar la información.

La biblioteca conserva información de versiones: cada pasaje corresponde a una versión del documento. Si reemplazas o vuelves a procesar un archivo, comprueba que la respuesta use la versión que necesitas.

Una extracción parcial puede dejar contenido sin consultar. Si falta el pasaje que buscas, revisa el original. Que una búsqueda no encuentre un término no demuestra que el documento no trate ese tema.

Ver una hoja de cálculo como documento es distinto de convertirla en una colección de datos. Para transformar filas en registros editables y consultables, sigue [Importar una hoja de cálculo](/es/docs/data/import-spreadsheet/). Para conservar hechos y preferencias entre conversaciones, usa la [memoria](/es/docs/everyday/memory/).
