# Manual verification

From `apps/site`, using Node 22 and the installed Google Chrome:

```sh
export PATH=$HOME/.local/opt/node/bin:$PATH
nice -n 10 pnpm check
nice -n 10 pnpm build
SITE_PORT=4334 nice -n 10 node --experimental-strip-types tests/docs/verify.ts
SITE_PORT=4334 nice -n 10 node --experimental-strip-types tests/docs/review.ts
```

`DOCS_SHOTS_DIR=/absolute/path` selects a fresh screenshot directory. The default
is `/home/cristhian/projects/ui-conceptos/landing/implementacion/docs/`.

The runner first checks that the production sitemap and routes exclude the
private draft and that Pagefind's index exists. It temporarily promotes the
fixture and makes it visible in the index for a separate test build, restores
the source immediately, then opens that build in Chrome. Its `finally` block
restores the draft, closes its browser, stops only a preview it started itself,
and builds the normal production site again. An existing preview on the
assigned port is reused and never stopped.

The screenshots exercise the home, long article, components, search and phone
index at 1280, 1536 and 390 pixels in both themes. Assertions cover rendered-text
contrast, token contrast (including generated labels), heading count, overflow,
search keyboard shortcuts/focus, tabs, clipboard copying, table-of-contents pen
position, theme persistence through the landing, locale navigation, reduced
motion, and native disclosures/mobile navigation without JavaScript. Extra
widths are 360, 1024, 1366 and 1920 pixels.

`measurements.json` records initial home and article JavaScript separately from
search's lazy modules, the custom enhancement's gzip size, and a ten-second
scroll at 4× CDP CPU throttling. Long-task and layout-shift measurements cover
the scripted scroll after load. Headless software rendering may inflate paint
cost. A reported longest task of zero means no task of 50 ms or more was observed.

Open the generated images and compare their typography, blue rail, leaders and
plate geometry with the approved blueprint and benchmark concepts. Automated
assertions do not replace this review. If `src/docs-sidebar.mjs` has not arrived
from the content worker, the original autogenerated index remains available;
the report marks this dependency and the real multi-area home still needs review.

`review.ts` captures the normal production homes in both locales and creates
local side-by-side comparison sheets using the approved concept images. These
reference images are never part of the site or its build output.
